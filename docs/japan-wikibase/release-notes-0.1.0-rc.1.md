# 0.1.0-rc.1 release notes

最初のlocal standalone release candidateです。日本語/Asia-Tokyo既定のMediaWiki/Wikibase Core、optional RDF query subsystem、logical Query Router、snapshot rebuild、incremental sync、A/B generation promotion/rollbackを含みます。

Core-only、Virtuoso、Fuseki/TDB2、Oxigraph profileをApple Silicon Docker Desktop上でqualificationします。Virtuosoがdefault、Fusekiがreference、Oxigraphがlightweightです。Blazegraph/WDQSは既存Wikibase Suite向けexternal compatibility laneです。

production backup、physical generation deletion、Kubernetes/Controller統合、hostname migration、production sizingは含みません。
